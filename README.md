# PG-TOL

PostgreSQL Training, Oversight & Learning Platform.

## Quick Start

```bash
# Start all services
bun run dev

# Stop services
bun run down

# Connect to database via CLI
bun run db:connect
```

## Services

* **Faculty Dashboard**: [http://localhost:3000](http://localhost:3000)
* **pgAdmin 4**: [http://localhost:80](http://localhost:80)
* **PostgreSQL**: `localhost:5432`
